# SmartCentres REIT Investment Analytics

Developed for **BSMM 8730 – Data Acquisition and Management**  
Odette School of Business, University of Windsor

## Project Overview
This project evaluates SmartCentres REIT from the perspective of a potential investor using an end-to-end data analytics pipeline. The analysis integrates company financial data, competitor benchmarking data, and Canadian macroeconomic indicators to support investment decision-making.

## Project Structure

- **Stage 1:** Company data acquisition and preprocessing
- **Stage 2:** Competitor benchmarking and market comparison
- **Stage 3:** Macroeconomic data acquisition and integration
- **Stage 4:** MongoDB integration, validation, and querying

## How to Run

1. Clone the repository.
2. Install the required Python libraries.
3. Before running Stage 1, upload the SmartCentres Annual Report PDF (included in this repository) to Google Colab. The notebook uses the uploaded report to extract the company's operational and financial metrics.
4. Execute the Stage 1 notebook to generate the company-level datasets.
5. Execute the Stage 2 and Stage 3 notebooks to generate the competitor and macroeconomic datasets.
6. Execute the Stage 4 notebook to integrate all processed datasets into MongoDB Atlas.
7. Use MongoDB Charts and Python visualizations to analyze the integrated datasets.
